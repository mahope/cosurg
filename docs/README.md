# Baggrundsdokumenter

*(English below)*

Materialet der lå til grund for projektet. Ikke nødvendigt for at køre CoSurg —
men det viser hvad vi byggede efter, og hvad vi lovede undervejs.

| Fil | Hvad |
|---|---|
| `SPEC.md` | Specifikationen skrevet torsdag morgen: scope, det der bevidst blev holdt ude, kliniske kilder, risici og færdig-kriterier. |
| `PLAN.md` | Den måldrevne arbejdsplan for byggedagen, med observerbare færdig-kriterier pr. mål. |
| `participant-brief.md` | Arrangørens challenge, regler og bedømmelseskriterier (fra Notion). |
| `schedule.md` | Programmet onsdag–fredag. |

# Background documents

The material the project was built from. Not needed to run CoSurg — but it shows what
we built towards, and what we committed to along the way.

| File | What |
|---|---|
| `SPEC.md` | The specification written on Thursday morning: scope, what was deliberately left out, clinical sources, risks and completion criteria. |
| `PLAN.md` | The goal-driven plan for the build day, each goal with an observable completion criterion. |
| `participant-brief.md` | The organiser's challenge, rules and judging criteria (from Notion). |
| `schedule.md` | The Wednesday–Friday programme. |

## Corti's own documentation

`corti-llms-full.txt` (2.7 MB, all of docs.corti.ai as markdown) and
`corti-llms-index.txt` served as a local reference during the build, so we could grep
the API documentation instead of browsing it. They are Corti's material, not ours, and
are therefore not part of the submission. Fetch them from
[docs.corti.ai](https://docs.corti.ai).
