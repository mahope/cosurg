## Hackathon — Schedule of Activities

### Wednesday — Optional Kickoff Evening

| Time (prov.) | Activity |
| --- | --- |
| 5-5:30 PM | Doors open, welcome. Name tags indicating background (medical / coding) |
| 5:40 PM | Brief intro & framing: what the hackathon is, expectations for the week |
| 5:50 PM | Clinical Innovation Team talk + Q&A: perspective from medicine real problems faced in healthcare and how AI can address them. |
| 6:10 PM | Product walkthrough + Q&A: speech-to-text ambient and dictation, text generation, agentic framework, medical coding, Corti Assistant |
| ~6:30 PM | Dinner - Pizza is served. |
| ~6:45 PM | Lamina demo: Demo of an app build off of Corti |
| ~7:00 PM | Housekeeping: intro of judges, Lovable free credits, MedDictate sample dataset shared with participants |
| 7:15 PM | Challenge statement announced |
| 7:30 | Team forming and mingling |
| 9 PM | Office closes |

You are encouraged to read the documentation and start brainstorming ideas after the kickoff, but no building yet.

### Thursday — Hacking Day 1

Doors 9:00 AM sharp · Office closes 10:00 PM

| Time | Activity |
| --- | --- |
| 9:00 AM | Prompt start. Quick team formation for anyone who missed Wednesday |
| 9:05 AM | Very brief recap of the product areas from the kickoff |
| 9:25 AM | Judging criteria — high points only: rubric attributes, superlatives, how to win. Reminder that final deliverable includes a demo + presentation to the group |
| 9:30- 10 AM | Write one sentence problem statement, solution, user journey sketch |
| 10:00 AM | Countdown → hacking begins (~9:30 AM) |
| 12:30 PM | Self-service lunch — no formal break |
| 3PM | Optional Check-in |
| Afternoon | Open hacking |
| 6:30-7:30 PM | Dinner - Salads |
| 6:00–10:00 PM | Optional social wind-down — drinks, snacks, ping pong. Informal; no one is forced to close their laptops |
| 10:00 PM | Office closes. Teams may continue working off-site at their own discretion — no mandated stop |

### Friday — Hacking Day 2, Presentations & Awards

Doors 8:00 AM · Evening open-ended

| Time | Activity |
| --- | --- |
| 8:00 AM | Doors open — early birds welcome to trickle in |
| Morning | Final hacking sprint |
| 12:30 PM | Self-service lunch available |
| 2:00 PM | Code freeze — hands off keyboards. Projects submitted to GitHub by deadline; |
| 2:00–3:30 PM (prov.) | Team presentations — Per team: ~5-min demo + presentation, ~2 min judges' Q&A. Tip offered to teams: preload transcripts. |
| 3:30–4:15 PM (prov.) | Judges deliberate (30–45 min) — drinks served, mingling for everyone else |
| ~4:30 PM (prov.) | Awards ceremony — held in the courtyard area (presentations happen in the office, awards outside). 1st / 2nd / 3rd place + superlatives. Big novelty check. Office in the office if bad weather |
| From ~5:00 PM | Social hour — drinks, dinner, networking. Open-ended; people stay and filter out as they like |
| Later evening | Migration to the nearby food court. |
